# Настройки kinopub

Личные настройки. Скилл читает их из `~/.config/kinopub/config.md` (или `$XDG_CONFIG_HOME/kinopub/config.md`); скрипт этот файл не читает.
id папки — из `run folders` или из ссылки `https://kino.watch/favorites/view?id=<id>`.

## Папка по умолчанию

- «<Название>» — id `<id>`, https://kino.watch/favorites/view?id=<id>
